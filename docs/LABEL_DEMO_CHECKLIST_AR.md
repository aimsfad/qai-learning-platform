# قائمة عرض 3alimnIA لملف طلب اللابل

## التسلسل المقترح للعرض

1. الصفحة الرئيسية: الفكرة، القيمة التربوية، المسارات، والتصميم المتجاوب.
2. فضاء المتعلم: لوحة التقدم ثم وحدة Qiskit ثم نموذج المحاولة قبل دعم AI Coach.
3. فضاء الأستاذ: مؤشرات المشاريع ثم رحلة بناء المقرر في خمس خطوات، مع التركيز على الخطة وإنشاء الدروس.
4. فضاء المقيّم/الباحث: مؤشرات الدراسة، LPQS، التحسن، تفاعلات الذكاء الاصطناعي، والرسوم التحليلية.
5. الهاتف: لقطة 390×844 لإثبات الاستجابة وتماسك الهوية.

## لقطات يفضل تضمينها في العرض

- Hero الصفحة الرئيسية.
- بطاقة مسار الحوسبة الكمية.
- Learner Dashboard.
- شاشة الدرس الثنائية: المحتوى + AI Coach.
- Teacher Workspace KPIs.
- رحلة الخطوات الخمس.
- Evaluator Dashboard KPIs + رسم تحليلي.
- صفحة الهاتف.

## قبل تصوير النسخة

- استخدم بيانات تجريبية غير حساسة.
- لا تعرض كلمات مرور أو ملف secrets.toml.
- اخفِ زر Manage app من اللقطات إن أمكن عبر نافذة غير مسجلة في Streamlit Cloud.
- استخدم نفس اللغة والـzoom في جميع لقطات العرض.
