# نظام التصميم الجديد — 3alimnIA V-Legend

## الفكرة
ملف واحد منظّم `.streamlit/theme.css` (621 سطرًا) يستبدل 4 ملفات CSS متراكمة
عبر ~190 تكرارًا سابقًا (`style.css` + `v4_theme.css` + `v6_theme.css` +
`v6201_responsive_visual_system.css` ≈ 8100 سطر، فيها 13 تعريف `:root` مكرر).

## الهوية البصرية
| الطبقة | الوصف | المتغيرات الأساسية |
|---|---|---|
| كحلي عميق | خلفيات القائمة الجانبية ورأس كل صفحة | `--qai-navy-900` … `--qai-navy-500` |
| أزرق رقمي | الأزرار الأساسية، التوهّج، الحالة النشطة | `--qai-blue-700` … `--qai-blue-300` |
| سماوي رقمي | لمسة "رقمية" مكمّلة (من شعار المنصة نفسه) | `--qai-cyan-500/400/300` |
| أبيض ناعم | خلفية الصفحة والبطاقات الزجاجية | `--qai-white-soft`, `--qai-mist` |
| زجاجية | `backdrop-filter: blur()` + شفافية + حدود خفيفة | `--glass-light*`, `--glass-navy*` |

النخب اللوني ليس اعتباطيًا: امتداد مباشر لتدرّج شعار المنصة الأصلي
(كحلي `#0A2A78` → أزرق `#1066D9` → سماوي `#12C8E6`) الموجود أصلًا في
`branding.py`، فقط تم تعميمه على المنصة كاملة بدل بقائه محصورًا بالشعار.

## عقد التوافق (لا تُغيَّر هذه الأسماء)
بعض ملفات Python (`main_app.py`, `branding.py`) تستدعي متغيرات CSS مباشرة
داخل `style="..."`. أُبقيت هذه الأسماء كما هي عمدًا:
`--qai-blue` · `--qai-border` · `--qai-navy` · `--qai-teal` · `--v48-rail-width`

## استراتيجية التغطية
بدل إعادة كتابة آلاف استدعاءات الأصناف (classes) داخل ملفات Python (خطر
عالٍ على وظائف تعمل حاليًا)، اعتمد الملف الجديد على:
1. إعادة تصميم كاملة لنفس أصناف نظام التصميم المشترك (`global_design_system.py`)
   المستخدمة عبر كل الصفحات: `v618-*`, `v6186-*`, `qai-hero`, إلخ.
2. محددات عامة (`[class*="-card"]`, `[class*="-chip"]`, `[class*="-step"]` …)
   تمنح أي صنف قديم بلاحقة معروفة نفس المعالجة الزجاجية الموحّدة تلقائيًا،
   حتى الأصناف الخاصة بإصدارات لم تُفرد لها قاعدة صريحة.
3. الحفاظ الحرفي على الآليات البنيوية غير الزخرفية: القائمة الجانبية الثابتة
   (`.v48-native-sidebar-marker`)، دعم RTL/LTR في `i18n.py`، نقاط الاستجابة
   لعرض 900px.

## ماذا لم يُغيَّر (عمدًا)
- منطق العمل في `main_app.py` / `teacher_studio.py` وغيرها — لم تُلمَس.
- آلية `i18n.py` لتبديل الاتجاه/الخط — لا تزال تعمل كما هي، وتستدعي
  نفس متغيرات CSS المحفوظة أعلاه.
- شعار العلامة التجارية (`branding.py`) — تدرّجه اللوني يطابق الهوية
  الجديدة أصلًا فتُرك كما هو.

## للمطوّرين لاحقًا
- الملفات القديمة محفوظة كمرجع فقط في `docs/legacy_css/` (غير محمّلة).
- فحوصات الإصدارات القديمة (`validate_v*.py`) محفوظة في
  `docs/archive/legacy_validators/` للتاريخ فقط؛ لم تعد تعكس التصميم الحالي.
- لإضافة صنف جديد ينسجم مع الهوية: استخدم `var(--glass-light-strong)` +
  `backdrop-filter: blur(var(--glass-blur))` + `var(--shadow-xs)` كنقطة بداية.
