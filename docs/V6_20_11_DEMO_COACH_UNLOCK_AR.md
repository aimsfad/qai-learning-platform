# V6.20.11 — فتح المدرّب الذكي مؤقتًا للعرض

هذه نسخة عرض مؤقتة لملف اللابل.

- أُلغي شرط المحاولة الأولى **فقط للوصول إلى أدوات المدرّب الذكي**.
- بقيت قواعد التحقق من المحاولة كما هي ولم تُحذف.
- بقي حفظ المحاولة المستقلة وإنهاء الدرس مرتبطين بالقواعد الأصلية.
- إذا طلب المتعلم الدعم دون محاولة، لا تُسجّل محاولة فارغة كدليل تعلم مستقل.
- تسجّل المنصة الحدث صراحة كـ `demo_support_request_without_attempt` حتى لا يختلط ببيانات المحاولة الأولى.
- لإعادة السياسة الأصلية بعد تسجيل الفيديو، غيّر السطر التالي في `attempt_gate.py`:

```python
DEMO_BYPASS_ATTEMPT_GATE = False
```

الهدف من هذا التعديل هو تسهيل العرض الحي للمدرّب الذكي دون المساس بالمنطق التربوي الأصلي أو حذفه.
