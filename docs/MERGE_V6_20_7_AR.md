# V6.20.7 — دمج التصميم الموحّد مع النسخة التشغيلية الحالية

## الهدف

دمج التعديلات الجمالية والتنظيمية الواردة في `qai_platform_redesigned.zip` مع النسخة الوظيفية النظيفة، من دون الرجوع عن إصلاحات الهاتف أو وظائف المعلم والمتعلم التي أضيفت بعد V6.20.1.

## ما تم اعتماده من نسخة الزميل

- الهوية البصرية الجديدة: كحلي عميق + أزرق رقمي + سماوي + أسطح زجاجية خفيفة.
- Design tokens الموحّدة وخطوط Alexandria / Tajawal / Inter.
- ألوان Streamlit الأصلية والرسوم البيانية المتناسقة مع الهوية الجديدة.
- ملف تصميم إنتاجي واحد `.streamlit/theme.css` بدل تحميل عدة ملفات CSS.
- دليل التصميم `docs/DESIGN_SYSTEM_AR.md`.
- ملفات تشغيل Windows `.bat` و`.ps1`.
- كامل مكتبة وسائط دروس Quantum/Qiskit.

## ما تم الحفاظ عليه من النسخة الوظيفية الأحدث

- رأس الهاتف V6.20.5 وعدم قص الشعار.
- Material Icons في مساحة المتعلم.
- AI Tutor compact header.
- منع تكرار عنوان قسم الدرس في مراجعة المعلم.
- عرض بطاقة المشروع الوحيدة بصورة أوسع.
- Published Course Runtime وإصلاحات V6.20 اللاحقة.
- تنظيف Python core وعدم إعادة `state.py` أو `ui_components.py` أو `pages/` placeholders.
- `.gitignore` الآمن لملفات قواعد البيانات وSecrets والـlogs.

## حماية CSS

لم يتم استبدال البنية القديمة عشوائيًا. تم الاحتفاظ فقط بعقود layout/DOM اللازمة لواجهات Streamlit الحالية، مع إزالة معظم التصريحات البصرية التاريخية حتى تكون الهوية الجديدة هي المصدر البصري الرئيسي. كما تم تضييق selectors العامة في تصميم الزميل حتى لا تتحول عناوين مثل `qai-builder-title` أو `qai-step-title` إلى بطاقات بالخطأ.

## الأمان

لم يتم إدراج `.streamlit/secrets.toml` من حزمة الزميل. يجب إبقاء أسرار Streamlit في Cloud Secrets أو في ملف محلي غير متتبع بواسطة Git.
