# V6.20.18 — دمج واجهة Glass UI

تم بناء هذا الإصدار فوق **V6.20.17 Public Catalog Sync** فقط، لذلك تبقى جميع إصلاحات الوظائف من V6.20.11 إلى V6.20.17 محفوظة.

## ما تم دمجه

- لوحة ألوان زجاجية بيضاء مع تدرج تركوازي–أزرق.
- إعادة ربط متغيرات التصميم القديمة بنظام Glass موحد.
- تحسين البطاقات، الأزرار، الحقول، التبويبات، الجداول، المقاييس والتنبيهات.
- تحسين الحضور البصري لفضاءات الأستاذ والمتعلم والمقيّم دون تعديل منطقها البرمجي.
- اعتماد إعدادات Theme الخاصة بالتصميم الجديد.

## التنظيف قبل الدمج

لم يتم نسخ المشروع الكامل الذي يحتوي على التصميم، بل تم أخذ **طبقة الواجهة فقط**. لم تُنسخ `.git` أو الأسرار أو الملفات التاريخية من نسخة التصميم.

تم كذلك حذف `@import` المتأخر لأن الخطوط موجودة أصلًا في بداية `app.css`، واستبدال selector عام واسع بطبقة آمنة تستهدف الحاويات الرئيسية فقط.

## الأداء والاستجابة

على الشاشات الصغيرة يتم خفض blur والظلال لتقليل تكلفة الرسم مع الحفاظ على الهوية الزجاجية. كما توجد fallback للأجهزة التي لا تدعم `backdrop-filter`.

## قاعدة الدمج

V6.20.17 هو الأساس الوظيفي. V6.20.18 هو **دمج Front-End انتقائي** ولا يغيّر قاعدة البيانات أو Workflow الأستاذ أو Runtime المتعلم أو تحليلات المقيّم.
