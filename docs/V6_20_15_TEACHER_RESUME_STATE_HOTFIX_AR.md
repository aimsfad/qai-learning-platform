# V6.20.15 — Teacher Resume & State Hotfix

هذا الإصدار يعالج أربع مشكلات مترابطة ظهرت أثناء تجهيز Demo اللابل:

- زر **متابعة الإنتاج** في بطاقة المشروع أصبح يستخدم callback + pending route ويُطبَّق المسار قبل إنشاء شريط تنقل Streamlit، لذلك يفتح مرحلة الاستئناف بصورة حتمية.
- بطاقة المشروع في الوضع المبسط تعرض تقدم الرحلة الحقيقية **من 5 خطوات** بدل مقياس المحرك القديم ذي 11 مرحلة؛ فلا يظهر 3/11 بينما مساحة المشروع تعرض 4/5.
- مشاريع `review` القديمة من الإصدارات السابقة لا تُعرض تلقائيًا كـ **معتمد للنشر** إذا كانت الدروس غير مكتملة أو كان اعتمادها قديمًا.
- اعتماد درس/جزء درس يحدّث `teacher_projects.updated_at` حتى يُبطل أي اعتماد نهائي أقدم من آخر تعديل للمحتوى.

لا يغير الإصدار محتوى الدروس أو بيانات المتعلمين أو منطق LPQS.
