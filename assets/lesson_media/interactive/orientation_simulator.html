Quantum circuit basics — interactive map

Step through how Qiskit code becomes a circuit diagram.

Qiskit code
from qiskit import QuantumCircuit
qc = QuantumCircuit(1, 1)
qc.measure(0, 0)
print(qc)
QuantumCircuit(1, 1) allocates one qubit (q0) and one classical bit (c0). The qubit starts in state |0⟩.
Result: c0 = 0
Notice: the circuit is not a sequential print statement — it is a structured map of quantum and classical resources, read left to right.
